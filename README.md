# Qazaq Heritage 🇰🇿

**Qazaq Heritage** is a responsive educational website dedicated to the history, culture, traditions, architecture, and natural heritage of Kazakhstan.

The project aims to present Kazakhstan's cultural identity through an accessible and interactive web experience. It was developed as part of the **Web Technologies 1 — Frontend** course.

🌐 **Live Demo:** [https://absultanov-n.github.io/SE-2504_Assignment6/](https://absultanov-n.github.io/SE-2504_Assignment6/)

## 📌 Project Overview

The website consists of four main pages:

| Page | Description |
|---|---|
| Home | Introduction to Kazakhstan's heritage, featured content, statistics, and FAQs. |
| Heritage | Information about historical landmarks, cultural traditions, and heritage categories. |
| Gallery | Visual collection of Kazakhstan's cultural and natural attractions, including an image carousel. |
| Contact | Contact and registration interface with form validation and interactive feedback. |

## ✨ Key Features

- **Responsive Design** — layouts adapted for desktop, tablet, and mobile screens.
- **Interactive Navigation** — navigation menus and page transitions.
- **Real-Time Search** — dynamically filters relevant content as the user types.
- **Autocomplete** — displays suggestions based on search input.
- **Search Highlighting** — highlights matching keywords in content.
- **Scroll Progress Indicator** — visual indicator of reading progress.
- **Animated Counters** — animated numerical statistics.
- **Form Validation** — validates user input and password confirmation.
- **Loading Spinner** — provides visual feedback during form submission.
- **Toast Notifications** — displays temporary status messages.
- **Copy to Clipboard** — allows users to copy selected information.
- **Lazy Loading** — loads images when they are needed, including carousel images.
- **Interactive Gallery** — image cards and carousel navigation.
- **FAQ Interactions** — expandable questions and answers.
- **Audio Content** — cultural audio playback.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/Absultanov-N/SE-2504_Assignment6.git
```

2. Open the project folder:

```bash
cd SE-2504_Assignment6
```

3. Open `index.html` in your browser.

An active internet connection is required to load external libraries through CDN links.
